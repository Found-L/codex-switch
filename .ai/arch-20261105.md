# Codex Switch v0.1.0

Windows-only, per-user installation; Python/Tk packaged with PyInstaller, no separate runtime on target PCs. GUI and CLI share one configuration service. Use Windows Credential Manager and the officially documented command-backed provider authentication. Never change auth.json or curated model catalogs.

Modules: config (format-preserving TOML, exclusive lock, backup, compare-before-replace), credentials (Win32 credential store), service (setup/status/use), GUI (Chinese/English onboarding and switching), CLI (secure setup, use, status, doctor, internal credential helper), packaging (per-user installer, portable ZIP, CI releases).

Scope: global CODEX_HOME only; existing chats, project/profile overrides and cached desktop catalogs can differ. Preserve original account login. API availability depends on project permissions; no invented model filtering. No automatic generated API requests or client restart. Do not import any local credential/config/backup into the repository.

Implementation role assigned to the current agent in this thread, followed by quality review and documentation roles. No subagents are started under the applicable skill guardrail.
