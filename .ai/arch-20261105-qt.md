# Desktop interaction refresh

The existing Tk implementation destroys/rebuilds its widget tree on every switch, causing visible redraw; it has neither a tray lifecycle nor consistent taskbar identity. Replace the GUI with a persistent Qt Quick scene and an asynchronous QObject controller. Keep the configuration/credential service and CLI independent of Qt.

Deliver a compact light utility panel, animated selection/page states, a mini-window mode, an actual system tray menu, one icon/AppUserModelID across shell surfaces, and single-instance activation per CODEX_HOME. Closing/minimizing hides to tray when tray support exists; the tray menu provides an explicit Quit action. Preserve all earlier model-setting removal and credential/config preservation work.

Implementation role assigned to the current agent. Validate persistent object identity during state changes, async setup/switch, mini/tray lifecycle, duplicate-instance activation, packaged QML/plugin availability, CLI credential latency, and installer/uninstaller preservation.
