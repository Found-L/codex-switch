# v0.2.0 验证记录

环境：Windows 11 x64，Python 3.14，PySide6 / Qt 6.12.0，PyInstaller 6.22.3，Inno Setup 7。Windows 10 尚未独立实机验收。

## 自动验证

- 17 项服务测试覆盖配置格式/编码保留、独立 Windows 凭据读写、失败回滚、模型与 auth.json 保留、并发修改检测、Profile 覆盖保护、第三方提供商与卸载清理。
- Qt 离屏自检加载真实 QML，完成 Key 配置及账号/API 异步往返，确认控件对象始终为同一实例、没有模型字段、372 × 302 小窗几何和单实例唤回协议。
- 离屏渲染中文连接、Key、终端、英文终端及迷你窗口，用于检查排版、图标与控件重叠。这不是实际托盘点击或动画流畅度的实机验收。
- 构建脚本运行服务测试、冻结 GUI 自检、打包 CLI 的隔离配置往返及凭据清理；CLI 排除 Qt，避免命令取钥加载图形运行库。
- GitHub Windows CI 另运行隔离安装/卸载，检查 PATH、配置恢复和凭据清理。以对应提交的 CI 结果为准。

## 实机验收边界

开发时已确认源程序注册 Windows 托盘，安全状态协议返回托盘可见。后续桌面锁定，尚未完成最终版本的实际托盘点击、窗口收起和动画主观流畅度验收。此记录不将离屏结果当作实机交互通过。

所有自动测试使用隔离配置和占位 Key，不调用付费模型，不验证真实 Key、额度、具体模型或速度档位。没有重启 Codex。工具显示全局配置，不能证明已有聊天或菜单缓存已热切换。安装包未购买商业代码签名。
